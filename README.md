# PARTYMOD Common Libraries
This is a collection of common libraries for the PARTYMOD series of patches.

## 🎉 PARTYMOD 🎉
PARTYMOD is a series of patches that provide various fixes and modernizations for the THPS series and other games on their engines.
[Other PARTYMOD Releases Available Here](https://partymod.newnet.city/)

## Libraries
### partymod-common
Common functions for the main patch. Everything from patching code at runtime to parsing command line arguments, handling config files, and handling controls.
### partymod-config-common
Common structs for configuring controllers.
### partypatcher-common
Implements a patcher meant for executable files.
### pgui
A (currently windows-only) library for native-style GUI applications. Meant for the config apps shipped alongside PARTYMOD releases.
